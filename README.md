# 💬 FeedSync

## 📌 About the Project

FeedSync is a feedback management application designed to
allow users to submit, organize, and manage feedback through
a centralized system.

The project was developed as part of my Computer Engineering
software development experience.

## 🎯 Objectives

- Provide a centralized feedback system
- Allow users to submit feedback
- Organize feedback by category
- Provide administrators with feedback management tools
- Store feedback data in a database

## ✨ Features

- 👤 User authentication
- 📝 Feedback submission
- ⭐ Rating system
- 📂 Feedback categories
- 🔒 Anonymous feedback option
- 🗄️ Database storage
- 📊 Feedback management
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MySQL / MariaDB
- Firebase Authentication
- Firebase Firestore
- Git
- GitHub
- Visual Studio Code

## 📂 Project Categories

Feedback can be organized into categories such as:

- Administrative Offices
- Facilities
- Faculty Departments
- Student Officers
- Students
- Classes
- Lectures
